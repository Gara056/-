# Какой ИИ подключать к Racion Studio

**Дата:** 8 сентября 2026  
**Статус:** рекомендация к ТЗ v0.9.1  
**Короткий ответ:** меня (этот чат в Cursor) — в приложение Юлии нельзя. В прод — адаптер: DeepSeek на тексты без ФИО, YandexGPT если в запрос попадают данные клиента. КБЖУ считает не ИИ.

---

## Меня можно?

**В разработке — да. В рантайме меню — нет.**

| Что | Я (Cursor Grok 4.6) | Модель в продукте Юлии |
|---|---|---|
| Где живу | этот агент в Cursor / облачном чате | API, который вызывает сервер приложения |
| Что умею здесь | ТЗ, код, промпты, эталон PDF, ревью | черновик шагов, тон «как подружка», замены, сетка из библиотеки |
| Вызов из PWA Юлии | нет такого API | `POST /v1/chat` у провайдера |
| Считать КБЖУ | не должен и продукт не должен мне это отдавать | запрещено ТЗ: цифры только `kbju-engine` |

xAI Grok как **отдельный API** — другая сущность, не этот чат. Из РФ те же проблемы, что у Claude/ChatGPT: оплата, юрисдикция, 152-ФЗ. Для голоса «как подружка» и РФ-продуктов выигрыша нет. **Не берём Grok в MVP.**

Итог: я остаюсь «инженером на стройке». В готовом меню клиент Юлии меня не видит и не должен.

---

## Что ИИ вообще делает в продукте

Разрешено:

- черновик шагов рецепта;
- комментарий нутрициолога в тоне Юлии;
- идея соуса и замен;
- черновик сетки **из библиотеки** под ограничения;
- (позже) разбор текста анкеты в поля карточки.

Запрещено:

- БЖУ, ккал, усушка, «сколько муки осталось»;
- диагнозы, анализы, «вылечит», «диетолог назначил»;
- водяной знак модели в PDF.

Поэтому «какая модель умнее считает калории» — неверный критерий. Нужна модель, которая **слушает схему JSON и не врёт цифрами**, потому что цифр в её ответе быть не должно.

## Сравнение под эту задачу

| Модель | Русский текст | Цена на одно меню | 152-ФЗ / ПДн | Оплата из РФ | JSON-схема | Вердикт |
|---|---|---|---|---|---|---|
| **DeepSeek** (то, чем Юлия уже считает в чате) | сильный, уже её привычный тон | копейки | нет, сервера вне РФ | без VPN, оплата API местами муторная | да, OpenAI-совместимый | **основной на MVP для обезличенных текстов** |
| **YandexGPT 5** | родной русский, спокойнее «подружки» | десятки ₽ за меню | да, РФ, рубли | да | да, Cloud Functions / AI Studio | **основной, если в промпт идёт бриф клиента** |
| **GigaChat** | нормальный русский | рубли, дороже Lite / дешевле MAX | да, РФ | да | да | запасной РФ-контур вместо Яндекса |
| Claude | лучшее следование «не выдумывай БЖУ» | дороже | нет | сложно | да | не MVP; эталон качества промпта при отладке |
| ChatGPT / Gemini | хорошо | средне | нет | сложно | да | не MVP |

Юлия уже выстроила операционку вокруг DeepSeek. Имеет смысл **сохранить этот голос в черновиках рецептов**, но вытащить из чата арифметику.

## Как подвязать (архитектура)

```
Юлия в PWA
    → API Racion Studio
        → kbju-engine          (без сети, без LLM)
        → llm-adapter
              ├─ provider=deepseek   если нет ФИО/телефонов/анализов
              └─ provider=yandex     если есть бриф клиента
        → Юлия жмёт «утвердить»
        → PDF без имени модели
```

Правила адаптера:

1. Один интерфейс: «вход JSON → выход JSON по схеме». Смена модели — переменная окружения, не переписка продукта.
2. Перед зарубежным API — маскирование: `Клиент А`, без телефона, без файлов анализов.
3. В ответе LLM **нет полей kcal/protein/fat/carb**. Если модель их прислала — отбросить, в лог «schema violation».
4. Стоп-слова из ТЗ режутся до показа Юлии.
5. Ключи API лежат на сервере, не в телефоне Юлии.

Оценка расхода на MVP (Юлия, 1–5 клиентов, несколько меню в месяц): **меньше 500 ₽/мес** на DeepSeek или сопоставимо на YandexGPT. Это не статья бюджета. Дороже люди и вёрстка PDF.

## Решение в ТЗ v0.9.1

**Дефолт MVP**

1. Тексты рецептов и комментарии — **DeepSeek API**, в промпте только блюдо, ингредиенты, ограничения без фамилии.
2. Парсинг анкеты и сетка «под Анну, без рыбы, 1650 ккал» — **YandexGPT 5**, данные не уезжают в Китай.
3. Если Яндекс не подключаем в первую итерацию — весь ИИ на DeepSeek, но **ФИО и контакты в промпт не попадают** (карточка клиента остаётся в нашей БД).
4. Cursor / Grok — разработка, не прод.

Когда блок A закроется, это либо подтверждается, либо меняется одна строка в конфиге — не архитектура.
